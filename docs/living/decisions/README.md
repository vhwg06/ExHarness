# Decisions

This directory contains accepted choices that crossed a decision boundary.

A decision is not a transcript and not a parking lot for proposals. Candidate design belongs in `../../worktree/` or another explicitly non-authoritative working surface until it is accepted.

Each material decision should state:

```text
id
status: ACCEPTED | PROMOTED | SUPERSEDED
accepted-at
accepted-by / acceptance boundary
context
choice
supporting evidence/judgment refs when applicable
rejected alternatives
consequences
promotion targets
what would reopen it
```

`PROMOTED` means the decision has been materialized into the relevant accepted authority view.
