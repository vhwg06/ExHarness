# Blackboard development artifacts

These are bounded work products exchanged by the development pipelines. They are not Living Docs and are not current-system truth.

Primary types:

```text
RESEARCH_ARTIFACT
  evidence / alternatives / constraints / unresolved questions

IMPLEMENTATION_INPUT
  accepted Research/SA handoff
  desired change / invariants / acceptance criteria / affected surfaces

IMPLEMENTATION_RESULT
  implementation outcome / verification refs / residual findings
```

An artifact may be accepted as development input without claiming the capability already exists. Living Docs change only when the delivered system changes.
