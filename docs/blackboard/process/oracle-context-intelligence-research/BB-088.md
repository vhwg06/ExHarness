Negative cases the Worker must prove by executed tests:

- A snapshotReader call with a revision other than the requested exact snapshot, or any working-tree read, fails the build test.
- An edge without AUTHORITATIVE_SOURCE provenance, snapshot-qualified ref or file digest fails validation.
- An import target outside roots becomes an EXTERNAL_BOUNDARY node; silently dropping it fails the test.
- dynamic import() and bare package specifiers produce no edge and appear in graph.limits.
- A malformed CONTEXT_GRAPH_EDGES_V1 file or unknown declared relation fails the build.
- Building twice from the same inputs yields a different graphId or edge order: test failure.
- A graph ref with unknown relation, hops 0 or 3, or an absent anchor yields a typed ProviderFailure, never a fuzzy match.
- More reachable paths than maxItems returns exactly maxItems in deterministic order with truncated:true.
- CURRENT evidence resolved against a graph built at an older snapshot is STALE; a composition without a CONTEXT_GRAPH authority is CURRENTNESS_UNVERIFIABLE; REQUIRED evidence then yields UNSATISFIED.
- Introducing a graph database, vector store or new package dependency, or editing provider seam/contract/facade files, fails repository scope verification.
