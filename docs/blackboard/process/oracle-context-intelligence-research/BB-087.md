Negative cases the Worker must prove by executed tests:

- A 5-byte REQUIRED item under a 6000-byte budget must resolve COMPLETE; a TypeError 'materializedBytes budget exceeded' is a failure.
- consumed.materializedBytes different from resolution.materialization.bytes, or any literal 40000, fails the accounting test.
- A REQUIRED evidence whose provider throws ProviderFailure SOURCE_FAILURE must return status UNSATISFIED with unresolved reason SOURCE_FAILURE; a thrown ProviderFailure from resolve() fails.
- An OPTIONAL evidence whose provider fails must return PARTIAL with its typed reason while REQUIRED evidence stays resolved.
- Planner BUDGET_EXHAUSTED for optional evidence must appear as BUDGET_EXHAUSTED, never MISSING.
- Materialization exceeding maxMaterializedBytes must yield BUDGET_EXHAUSTED (UNSATISFIED if REQUIRED) and never a resolution whose consumed exceeds budget.
- A requirement whose evidence is all UNSUPPORTED (zero reservations) must report providerCalls 0, never a floored 1.
- Source snapshot change between pre and post observation must still throw DurabilityFailure STALE_DURING_RESOLUTION.
- Edits to contract, planner, catalog, provider, durability, Core or agentic files fail repository scope verification.
- A durability stub returning REUSED must be returned unchanged; the facade must not re-plan or re-account a reused resolution.
- resolve() dropping execute() failures diagnostics, or placing them inside ContextResolution, fails the accounting test.
