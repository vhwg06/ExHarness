## Discriminating experiment

No task-local probe was executed. The design rests on the delivered sources and on the planned contracts listed under Handoff. The Worker must establish the negative cases below by execution.

Negative cases the Worker must prove by executed tests:

- Running --mode run with an uncommitted, modified or digest-mismatched protocol is refused before any attempt.
- A cohort containing any BB-065 calibration or BB-077/BB-081 reserved digest fails selection; fewer than 6 eligible tasks stops PLAN_INPUT_CONTRADICTION.
- Re-running selection with the same seed yields a different cohort: test failure.
- Any unit with UNKNOWN required tokens, cost or quality makes the decision INCONCLUSIVE, never PUBLISH.
- Any provenance or currentness violation in O2 prevents PUBLISH even if all ratios pass.
- A task where O2 accepted-success count is below O1 blocks PUBLISH regardless of aggregate ratios.
- Reduce mode producing a decision different from the recorded one fails.
- benchmark-profile.mjs retaining any `|| true` assertion fails the benchmark-contract test.
- Writes under packages/** or benchmarks/substrate/** fail repository scope verification.
