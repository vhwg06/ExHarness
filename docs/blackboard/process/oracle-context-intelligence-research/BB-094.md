## Research questions

Each objective criterion was a research question; the READY plan resolves it with the listed decisions, acceptance criteria and verification runs.

1. Specify a conformance suite resolving Oracle requirement blocks through Core createAgentRuntime on CORE_SYNC and, only when published, CORE_ASYNC_FIRST_V1, with fail-closed pre-render behavior per profile.
   Resolved by D1, D2, D3; criteria CI1; verification `conformance`.
2. Specify the async rule: a resolution is pinned to one agent call; a wake/resume performs a new call that re-resolves or reuses only a CURRENT receipt, never a STALE one.
   Resolved by D4, D6; criteria CI2; verification `conformance`.
3. Specify the frozen ORACLE_CORE_INTERACTION_V1 protocol (2x2 when async is published, otherwise 1x2 with async NOT_EVALUATED) reusing ORACLE_CONTEXT_BENCHMARK_V1 fixed factors, validated offline.
   Resolved by D5, D7; criteria CI3; verification `protocol`, `core-regression`.
4. Produce an exact file-level plan, negative cases and executable verification for fresh Jev readiness.
   Resolved by D1, D5; criteria CI1, CI2, CI3; verification `conformance`, `protocol`, `core-regression`, `repository`.

## Discriminating experiment

No task-local probe was executed. The design rests on the delivered sources and on the planned contracts listed under Handoff. The Worker must establish the negative cases below by execution.

Negative cases the Worker must prove by executed tests:

- A second resolver call within one agent call, or zero calls on a second agent call, fails conformance.
- UNSATISFIED or STALE_DURING_RESOLUTION reaching the fake model (non-zero model/capability calls) fails conformance.
- A restored runtime rendering a prior projected block without calling the resolver fails the resume test and triggers PLAN_INPUT_CONTRADICTION.
- Reusing a receipt whose source changed after snapshot fails the durability resume case.
- Executing async cells while BB-081 is not DONE with PROMOTE_ASYNC, or omitting a NOT_EVALUATED record, fails the protocol test.
- Any edit under packages/** fails repository scope verification.
