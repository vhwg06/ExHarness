## Discriminating experiment

Executed research evidence:

- `docs/blackboard/evidence/BB-091/continuation-probe.mjs`
- `docs/blackboard/evidence/BB-091/continuation-probe-result.json`

Negative cases the Worker must prove by executed tests:

- An arm that bypasses SourceCatalog validation or reads working-tree files fails the ablation test.
- A strategy that weakens EXACT/CURRENT, drops provenance or exceeds reserved items/bytes fails the strategy parity tests.
- A cohort query whose relevant set is edited by hand (cohort digest mismatch with regenerated cohort) fails the ablation test.
- Forced identical selections across all arms must yield INCONCLUSIVE_NON_DISCRIMINATING, never RECOMMEND.
- A candidate with any per-query recall below A0 must not be recommended even if its mean is higher.
- Re-reducing a recorded report in validate mode with a different decision fails.
- Changing the default createRetrievalPlanner behavior or editing retrieval-planner.js fails repository scope verification.

## Required product evidence

- **PL1**: The ablation runs every arm through the delivered SourceCatalog/RetrievalPlanner path over a frozen, mechanically derived cohort and reports INCONCLUSIVE_NON_DISCRIMINATING when arms select identical items. Evidence: Harness report with cohort digest and a forced non-discriminating fixture result.

Evidence: Reducer reproduction output, unchanged default planner tests, Living Doc diff and repository verify log.
