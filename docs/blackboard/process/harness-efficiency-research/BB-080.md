# BB-080 — Integrate async steering, wakeup and recovery

Status: RESEARCH INPUT; no implementation authority.

## Outcome

ExHarness can accept new input, coalesce operation completions and recover/cancel safely while detached operations are in flight.

## Current gap

Detached tools introduce scheduling races: completion storms can trigger redundant model turns, user steering can race with model/tool work, and process failure can lose wakeups unless event ordering and recovery are explicit.

## Research questions

1. Define deterministic event ordering and coalescing window semantics without delaying interactive steering excessively.
2. Define model-cancel behavior when user steering arrives during generation.
3. Specify restart reconstruction for scheduled-but-not-yet-dispatched and dispatched-but-not-terminal operations.
