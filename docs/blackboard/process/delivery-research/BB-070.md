# BB-070 — Deliver product from goal and partial artifacts across owned domains

Status: RESEARCH CONVERGED; implementation remains unauthorized until canonical readiness publication.

## Selected architecture

BB-070 adds a thin product-entry/lifecycle composition over existing ExHarness authority. It does **not** add a generic workflow engine, role router or second scheduler.

- `PROJECT_SEED_V1` is the only entry envelope and supports exactly `GOAL_ONLY | REQUIREMENTS_DESIGN | EXISTING_CODE`.
- Missing authoritative product choices become typed `PRODUCT_DECISION_REQUEST_V1` blockers. The system may surface evidence; only product-owner authority resolves the choice.
- PM/BA/SA/FE/BE/DevOps/QA are semantic obligation owners for this supported profile, not a generic role registry.
- Domain work is materialized through the existing organization/cross-domain contracts. FE and BE progress independently when direct semantic prerequisites allow it.
- Closure delegates to the delivered BB-055 completeness/currentness boundary and exact BB-069 reference release/runtime. Runtime success or a browser pass cannot close the product.
- Playwright **v1.63.0** is the selected live browser-evidence adapter only.
- LangGraph **v1.2.12** is rejected as runtime orchestration because it would duplicate application/domain authority.
- OpenHands software-agent-sdk **v1.49.6** stays upstream in BB-066/069; BB-070 consumes the delivered runtime seam instead of embedding the SDK.
