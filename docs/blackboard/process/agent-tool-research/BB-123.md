## Outcome

Grok costs stay observed-only (only a finite `total_cost_usd` number >= 0 is a cost, anything else is null) and grounded context is excluded worktree-locally, so no run fabricates a $0 cost and no grounded run writes the source repository.

## Current gap

- **DELIVERED_TRUTH.** `packages/agent-tools/src/output-parsers.js` `parseGrokJson` computes `const cost = Number(value.total_cost_usd)`. Probe: usage-bearing JSON with `total_cost_usd` null/`""`/true/`"0.5"` recorded `totalCostUsd` 0/0/1/0.5, so a null cost is recorded as an observed $0 cost.
- **DELIVERED_TRUTH.** `packages/agent-tools/src/task-context.js` `projectAgentTaskContext` appends `.exharness/` to `git rev-parse --git-path info/exclude`. Probe on a scratch source repo plus a linked worktree from the delivered `createLocalGitWorkspace`: the resolved exclude path is outside the worktree and the source `info/exclude` gained the `.exharness/` line, contradicting the Living claim that the source repository is never written.
- **PLANNED_CONTRACT.** BB-105 specifies the grok adapter and parser; BB-102 specifies Oracle-grounded projection. Neither authorizes cost coercion or source-repo writes.
- **RESEARCH_DESIRED_STATE.** Observed-only cost guard; worktree-local `.exharness/.gitignore` exclusion. Copies still never enter the candidate commit.

## Approaches and evidence

- **Selected: observed-only cost guard.** Report `total_cost_usd` only when `typeof === "number"`, finite and >= 0; numeric zero stays an observed 0. Rejects the `Number()` coercion without touching token parsing or adapters.
- **Selected: worktree-local `.exharness/.gitignore` containing `*`.** Keeps `git status` clean and copies out of the candidate commit without opening any git metadata path for writing.
- **Rejected: keep the info/exclude append but skip linked worktrees.** Still writes the source repository for non-linked checkouts and keeps the shared-metadata hazard.
- **Out of scope:** Oracle resolution, budgets, snapshot authorities, the agentic-system workspace adapter, Codex/Kiro/agy/grok argv, and `observation.js` `mergedEnv` redaction scanning.

## Discriminating experiment

Usage-bearing grok JSON cost matrix through `parseGrokJson` (null/`""`/true/`"0.5"` must read null; 0 and 0.5 stay observed); scratch source repo plus linked worktree through `projectAgentTaskContext` (source `info/exclude` byte-identical, copies excluded from the candidate).
