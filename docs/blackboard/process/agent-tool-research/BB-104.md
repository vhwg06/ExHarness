### Probe findings

- **CLI (DELIVERED_TRUTH).** Dispatch is `if (command === "run"|"report"|"probe"|"smoke")`. There is no `deliver` command (`hasDeliverCommand` false). `unavailableResult` prints `AgentTaskStatus.TOOL_UNAVAILABLE`. Smoke prints `reason: "NOT_INSTALLED"` and exits 0 (skip). Deliver of a real slice must not copy that skip-success: missing executable is `TOOL_UNAVAILABLE` / `NOT_INSTALLED` and never `ACCEPTED` (non-zero exit). `parseOptions` already accepts `--slice` / `--recovery-dir` as flag/value pairs. Tool ids are exactly `codex`, `kiro`, `agy`.
- **Supervisor (DELIVERED_TRUTH).** Exports `runSupervisedTask`, `validateAgentTask`, `AgentTaskStatus` = `{ ACCEPTED, EXHAUSTED, TOOL_UNAVAILABLE }`. Options include `invocationObserver = null`. There is no `recoveryDir`, no `resumeSupervisedTask`, no `runDeliverSlice`. `validateAgentTask` freezes `{ id, repositoryRoot, baseRevision, prompt, verifications }` and drops `requiredFiles`. `supervisor.js` statically imports `../../agentic-system/src/index.js`.
- **QA seam (DELIVERED_TRUTH, executed).** `createLocalCommandVerifier({ requireUnchangedTree: true })` (default true) returns `VerificationStatus.FAIL` with `LocalVerificationReason.TREE_MUTATED` when the command writes a file, and `REVISION_MISMATCH` when `candidate.version !== HEAD`. `createLocalGitWorkspace` is `git worktree add --detach` at a 40-hex sha. After `runSupervisedTask` FIX_FIRST `ACCEPTED`, `acceptedSha` is checkoutable from the source object store; a QA verifier at that sha PASSes; source HEAD/porcelain are unchanged. `runBackendThenQaObjective` in `composition.js` does not import agent-tools.
- **BB-100 READY (PLANNED_CONTRACT).** Public names `mapBackendOrderToAgentTask` and `runSupervisedBackendWork` in `packages/agentic-system/src/supervised-backend.js`. Mapped `AGENT_TASK_V1` has **no** `requiredFiles` field. `runSupervisedBackendWork` options have **no** `recoveryDir`. Agent-tools is forbiddenWrite on that task. The draft's call to `runSupervisedBackendWork` cannot carry BB-101 resume or BB-102 context.
- **BB-101 READY (PLANNED_CONTRACT).** `runSupervisedTask({ recoveryDir, onHandleWrite })`, `resumeSupervisedTask`, `readAgentToolRunHandle`, `disposeRecoverableRun`, handle path `recoveryDir/handle.json`. **`HANDLE_COMPLETE` refuses resume when status is `ACCEPTED`, `EXHAUSTED` or `TOOL_UNAVAILABLE`.** A two-stage slice that calls `resumeSupervisedTask` after Backend `ACCEPTED` would throw; it must skip Backend and run QA on `handle.candidateSha`.
- **BB-102 planned (PLANNED_CONTRACT).** Optional `requiredFiles` on `AGENT_TASK`; omitted or `[]` stays byte-identical. Pass through when the slice lists them; tests without them still run.
- **Living.** `docs/living/system/agent-tools/operator.md` does not exist. Living docs must not contain Blackboard ids (`scripts/current-docs-verify.mjs`).
