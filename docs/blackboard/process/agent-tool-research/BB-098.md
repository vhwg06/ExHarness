# BB-098 — Observe supervised and direct agent-tool runs

Status: RESEARCH INPUT; no implementation authority.

## Outcome

Every agent-tool invocation, whether direct or ExHarness-supervised, produces one normalized, append-only, secret-redacted run trace. The trace combines:

- tool-native output;
- ExHarness events and spans;
- timing;
- repository diff statistics;
- verification outcomes;
- reported token usage.

Unreported values stay null with a reason; they are never estimated. A deterministic report aggregates traces per tool and arm.

## Current gap

- **DELIVERED_TRUTH.** Core exposes `eventSinks` (`write(event)`) and `createTraceRecorder({ sinks })`, which records MODEL, CAPABILITY, ACTION, STRATEGY and AGENT_RUN spans. Nothing persists them, joins them with external tool output, or compares runs.
- **Executed BB-097 probe.**
  - Only Codex exposes a structured event stream (`codex exec --json`).
  - agy exposes `--log-file`.
  - Kiro 2.24 non-interactive output is plain text.
  - Token usage is therefore not uniformly available.
- **PLANNED_CONTRACT.** The BB-065 `@exharness/benchmark` package owns attempts, evidence manifests and accounting. BB-098 must not duplicate them; it produces evidence that BB-099 attaches.

## Research questions

1. What is the minimal trace schema that serves both a direct run and a supervised run?
2. Which metrics are truthfully observable per tool, and how is "not reported" represented?
3. How are secrets kept out of stored traces?
4. How do traces stay evidence and never become acceptance?

## Approaches and evidence

- **Selected: JSONL trace plus per-tool output parsers.**
  - The Codex JSONL parser reads usage only from events that carry it.
  - The agy log file and Kiro stdout are stored as digests plus bounded excerpts.
  - Core events and spans are written through their existing sinks.
- **Rejected:**
  - An OTel or Langfuse exporter as the source of truth. It is an external dependency and not needed for a deterministic report; it can be added later as another sink.
  - Estimating tokens from text length. That fabricates evidence.
- **Redaction:** environment-derived secret values and common key patterns are removed before anything is written. A test asserts that a planted secret never appears on disk.

## Discriminating experiment

A fake Codex JSONL stream, a fake agy log and fake Kiro stdout are driven through BB-097's fake-CLI fixtures. The results must be:

- exact token fields for Codex;
- null tokens with a reason for Kiro and agy;
- identical traces from identical inputs;
- rejection of an edited trace that no longer matches its digest.
